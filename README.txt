bodorマニュアル GitHub Pages PWA 公開用（UESアイコン版）

1. ZIPをWindowsで展開してください。
2. GitHubで公開用のPublicリポジトリ bodor-manual を作成してください。
3. 展開したフォルダの中身（index.html、sw.js、mobile.css、manifest.webmanifest、icon-*.png、.nojekyll）をリポジトリ直下にアップロードしてください。ZIPファイルそのものをアップロードしないでください。
4. Settings > Pages > Deploy from a branch > main > /(root) > Save。
5. https://ユーザー名.github.io/bodor-manual/ をSafari/Chromeで開き、オフライン準備完了表示を確認してください。
6. ホーム画面に追加してから機内モードで起動し、メニュー・詳細・写真を確認してください。

注意: GitHub Pagesは一般公開です。公開前に社外秘情報を確認してください。
注意: 実機iPhone/Androidでの動作は未検証です。保存データはブラウザ側で消去される場合があります。
注意: 本HTMLは24MB程度で初回読み込みに時間がかかります。
